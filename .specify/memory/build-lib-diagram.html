Default contract: one build_lib() call returns libraries, medoids, models, and assessments. The 1,000-spectrum sample is a development probe only; official assessment uses complete candidate and legacy artifacts.

Call build_lib()
one public entry point
The official workflow script now contains setup plus one default call. Advanced callers can still supply an OpenSpecy object and named stage arguments.
Official end-to-end mode?
x omitted or output_dir supplied
Omitting x selects source discovery and the whole official workflow. Supplying x with no output directory preserves composable library-only behavior.
Composable custom build
named recipe OpenSpecy objects
The compatibility path applies requested normalization, lookups, filters, deduplication, processing, and pruning without official release side effects.
Resolve default paths
data · source · workflow · output · legacy
Environment-aware defaults live in the function signature. Explicit arguments override all path locations.
Fingerprint build contract
files + checksums + args + package + code
A deterministic signature covers inputs relevant to safe restart. Any changed source, lookup, argument, package contract, or builder code invalidates downstream reuse.
reuse = TRUE and manifest matches?
stage-by-stage decision
Only completed artifacts with compatible signatures are reused. reuse = FALSE forces every stage to rebuild.
Load completed checkpoint
status = reused
Libraries, each medoid/model, split/evaluation results, and assessments have independent restart points.
Discover, read, and merge sources
raw + processed spectra
Source discovery, joining, axis alignment, and intensity conversion report elapsed time and before/after counts.
Standardize and coalesce metadata
canonical internal values first
Populated canonical values win; reviewed aliases such as user_name fill only blanks before external joins. Fills and conflicts are reported.
Exact curated joins
classes_reference + library_types
Exact class and canonical organization lookups run first. fallback_by is not used officially and is deprecated in general lookup specifications.
Regex completion and hierarchy
only unresolved classes
Variable regex rules fill blanks only and report overlaps/unmatched values. Literal-only rules live in classes_reference.csv. Hierarchy follows classification.
Identity cleanup, exclusions, dedupe
audited row decisions
Stable identities are cleaned, excluded IDs removed, duplicate spectra resolved, and counts captured for assessments.
Build three recipes
raw · derivative · nobaseline
Canonical aligned OpenSpecy objects feed each recipe with progress and preserved metadata/attributes.
Prune and apply final policies
classes · superseded · filters · drops · rounding
Every pruning pool/class reports progress. Superseded and one-off filters, metadata drops, coverage checks, and rounding are builder-owned.
Library checkpoints
atomic component exports
Every completed library is written atomically before downstream work begins, limiting loss on long-run failure.

Compatibility inventory
IDs · axes · metadata · counts · shape
Candidate and legacy artifacts are compared for identifiers, axes, metadata, classes, techniques, warnings, and object validity.
Combined grouped 90/10 split
stable current or legacy content identity
A seeded split uses the complete combined population. sample_name_old links rebuilt spectra to legacy identities so the same spectrum cannot cross train/test.
Reference holdout identification
test 10% against each source's 90%
Test groups are removed before correlation matching, preventing exact self-matches. Results retain per-spectrum class and score.
Model holdout identification
new models retrained on 90%
Candidate models train only on matching training references. Legacy model results are labeled compatibility evidence because original training membership is unknown.
